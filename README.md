# Furai's Digital Canvas

# PROMPT MAESTRO PARA LOVABLE — FURAI OMAKASE

Quiero que diseñes y desarrolles una página web completa, premium, cinematográfica, elegante, contemporánea y altamente visual para un restaurante japonés llamado:

# FURAI OMAKASE

**El primer omakase de Villavicencio.**

La web debe sentirse como una experiencia digital creada por un estudio especializado en branding, dirección de arte, fotografía gastronómica y diseño web premium.

NO quiero una plantilla genérica de restaurante.

NO quiero una landing page convencional.

NO quiero una web que parezca generada automáticamente por IA.

Quiero una experiencia digital que transmita la sensación de estar entrando en un restaurante japonés íntimo, donde el producto, el chef, la técnica y el momento de servir tienen todo el protagonismo.

La web debe combinar:

**CULTURA JAPONESA + SUSHI DE AUTOR + LUJO DISCRETO + FOTOGRAFÍA CINEMATOGRÁFICA + DISEÑO EDITORIAL + EXPERIENCIA SENSORIAL + CONVERSIÓN.**

El resultado debe hacer que un visitante piense:

**“Quiero vivir esta experiencia. Quiero sentarme frente al chef. Quiero reservar.”**

# 05. TIPOGRAFÍA

La tipografía debe tener protagonismo real.

Utilizar un máximo de dos familias tipográficas principales.

### TITULARES

Preferencia:

- Cormorant Garamond.
- Como alternativa, Playfair Display.

Utilizar una serif editorial sofisticada, con contraste entre trazos y una presencia elegante.

Aplicación:

- Titulares del hero.
- Mensajes principales.
- Nombres de secciones.
- Frases de marca.
- CTA editoriales.
- Textos breves de gran impacto.

### TEXTOS FUNCIONALES

Preferencia:

- Inter.
- Como alternativa, una sans serif contemporánea de alta legibilidad.

Aplicación:

- Navegación.
- Descripciones.
- Formularios.
- Botones.
- Horarios.
- Dirección.
- Menú.
- Información práctica.
- Footer.

### JERARQUÍA TIPOGRÁFICA

Los titulares deben tener tamaños generosos y una composición editorial.

Utilizar:

- Títulos grandes.
- Frases de dos o tres líneas.
- Etiquetas pequeñas en mayúsculas.
- Numeración de secciones.
- Textos secundarios discretos.
- Interlineados cuidados.
- Contrastes de escala.
- Espaciado tipográfico intencional.

Ejemplo de composición:

EL ARTE DE

**ESPERAR.**

Y DEJARSE

**SORPRENDER.**

Esta frase es una propuesta creativa de dirección de arte, no una afirmación sobre un ritual específico del restaurante.

NO utilizar tipografías japonesas decorativas como sustituto de una identidad profesional.

NO llenar la web de caracteres japoneses sin contexto.

NO utilizar demasiadas familias tipográficas.

NO utilizar textos diminutos que dificulten la lectura.

# 15. RESERVAS POR WHATSAPP

Esta es la principal sección de conversión.

Fondo crema o espresso, dependiendo del ritmo visual de la página.

Etiqueta:

**07 / TU PRÓXIMA EXPERIENCIA**

H2:

**TU LUGAR EN LA BARRA TE ESPERA.**

Texto:

**Cuéntanos cuándo te gustaría visitarnos y para cuántas personas. Prepararemos tu mensaje para que puedas consultar tu reserva directamente por WhatsApp.**

IMPORTANTE:

La web NO debe disponer de un sistema de reservas real.

NO consultar disponibilidad de mesas.

NO confirmar automáticamente reservas.

NO bloquear horarios.

NO gestionar capacidad.

NO guardar solicitudes.

NO enviar formularios a una API propia.

NO crear una base de datos.

NO crear un backend.

El formulario debe generar un mensaje y abrir WhatsApp para que el restaurante y el cliente continúen la conversación.

### CAMPOS

- Nombre.
- Fecha deseada.
- Hora deseada.
- Número de personas.
- Ocasión.
- Preferencia de espacio: barra omakase o mesa.
- Mensaje adicional, opcional.

El campo de preferencia de espacio debe aclarar que está sujeto a confirmación del restaurante.

### VALIDACIÓN

Validar los campos obligatorios antes de generar el mensaje.

La fecha debe ser igual o posterior al día actual, usando la fecha local del navegador.

El campo de hora debe permitir introducir una hora deseada, sin afirmar que existe disponibilidad.

El número de personas debe ser un valor válido y positivo.

Mostrar mensajes de error claros, junto a los campos correspondientes.

No borrar los datos del formulario si existe un error de validación.

### BOTÓN

**PREPARAR RESERVA POR WHATSAPP**

Al pulsar:

1. Validar los campos.
2. Construir un mensaje legible con los datos.
3. Codificar el mensaje correctamente para URL.
4. Abrir WhatsApp mediante un enlace wa.me.
5. Utilizar el número oficial del restaurante.
6. No guardar la información en la web.
7. No mostrar una confirmación falsa de reserva.

Mensaje sugerido:

Hola, Furai Omakase. Me gustaría consultar una reserva.

Nombre: [nombre]

Fecha deseada: [fecha]

Hora deseada: [hora]

Número de personas: [cantidad]

Ocasión: [ocasión]

Preferencia de espacio: [preferencia]

Mensaje adicional: [mensaje]

¿Podrían confirmarme la disponibilidad y las condiciones de la reserva?

El mensaje debe generarse dinámicamente con los valores introducidos.

- Desplazamiento mínimo de flecha.

- No recortar elementos importantes.
